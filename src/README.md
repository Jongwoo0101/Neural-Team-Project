## 프로젝트 폴더 구조 설명

본 프로젝트는 신경망(Neural Network) 모델을 학습·평가하기 위한 코드 기반으로 구성되어 있으며, 각 폴더는 다음과 같은 역할을 수행합니다.

### 📁 src/
신경망 실험을 수행하는 **메인 작업 경로**입니다.  
모델 학습, 하이퍼파라미터 테스트, 성능 비교 등의 실행 파일이 포함되어 있습니다.

### 📁 common/
프로젝트 전반에서 공통으로 사용되는 유틸리티 함수들이 포함된 폴더입니다.  
예:
- 수치 미분 및 gradient 계산 함수  
- Optimizer(Adam, SGD, Momentum 등)  
- 활성화 함수, 손실 함수 등 핵심 구성 요소

### 📁 data/
MNIST 등의 **데이터셋**과 이를 불러오는 **데이터 로더 함수**가 포함됩니다.  
모델의 학습·검증에 필요한 입력 데이터를 제공합니다.

### 📁 models/
신경망 구조 정의 파일이 위치합니다.  
예:
- 2층 신경망 (TwoLayerNet)  
- 다층 신경망 (MultiLayerNet, MultiLayerNetExtend)

모델 아키텍처를 변경하거나 새로운 네트워크 구조를 추가할 때 사용됩니다.

### 📁 test/
여러 모델과 설정을 대상으로 **실험 및 성능 비교**를 수행하는 스크립트가 포함됩니다.  
예: Optimizer 비교, BatchNorm 실험, Dropout 영향 분석 등

---

이 구조를 기반으로 다양한 실험 환경을 쉽게 구성할 수 있으며,  
모델 학습·평가 과정의 재사용성과 확장성을 높이도록 설계된 프로젝트입니다.
